# Mobile UI Design

Use this skill when designing or implementing TMS mobile interfaces.

## Goals

Create interfaces that are:

* Professional
* Consistent
* Mobile-first
* Accessible
* Easy to scan
* Fast to use
* Production-ready

## Process

Before implementing UI:

1. Inspect existing screens.
2. Inspect existing components.
3. Inspect the design system.
4. Identify reusable patterns.
5. Understand the user workflow.
6. Design the hierarchy.
7. Implement the UI.
8. Implement loading, error, and empty states.
9. Validate responsiveness and accessibility.

## Rules

* Reuse existing components.
* Follow the existing design system.
* Do not introduce arbitrary colors.
* Do not introduce arbitrary spacing.
* Avoid unnecessary gradients and decoration.
* Keep screens focused.
* Use clear visual hierarchy.
* Use appropriate touch targets.
* Do not put API logic directly in UI components.
* Keep route files thin.

## TMS Priority

Task information should be easy to scan.

1. Task title
2. Status
3. Priority
4. Due date
5. Assignee
6. Progress
7. Actions
